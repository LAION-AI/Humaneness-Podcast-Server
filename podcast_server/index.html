What happens behind the scenes?
The full Podcast model generates independent candidates for each turn. Humaneness Ears and ECAPA select the most genuine, reference-like take. The server checks the words, conservatively trims outer silence, inserts your pauses and exports the episode.
Model scores and ASR checks can be wrong. Review flags stay visible. An error retries unfinished work; it never silently replaces the chosen scoring formula.
